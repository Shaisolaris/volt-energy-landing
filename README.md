# Volt

Gen Z energy drink landing with smooth-scroll motion design.

**[Live Demo](https://shaisolaris.github.io/volt-energy-landing/)**

## Features

- Lenis smooth-scroll interactions
- Bold Gen Z visual identity
- Flavor showcase sections
- Newsletter capture with confirmation

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
